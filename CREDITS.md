# Seali: thanks and credits

Thank you to **JunkFood02** for creating [Seal](https://github.com/JunkFood02/Seal), sharing its source under GPL-3.0, and building the foundation continued by Seali. Thanks also to Seal's original contributors and translators. Their work and authorship are not claimed as new Seali work.

Seali is maintained independently by **Rahul Muraleedharan (@frpboy)** at [frpboy/Seali](https://github.com/frpboy/Seali). It is not an official release of, or endorsed by, JunkFood02. The repository name and installed application ID are Seali's; upstream credit is attribution, not Seali support or sponsorship routing.

## History and notices

The original Git history, authorship, [GPL-3.0 license](LICENSE), copyright notices and third-party license notices remain intact. Historical changelog release links and audit evidence continue to name the original project accurately. [UPSTREAM.md](UPSTREAM.md) records the origin and maintenance policy.

## Dependencies and other contributors

Seali also relies on yt-dlp, youtubedl-android and its contributors, FFmpeg, aria2, Termux, Kotlin, Android Jetpack, and the other libraries and artwork credited in the app's Credits page. This acknowledgement does not replace their licenses or required notices.

The current `io.github.junkfood02.youtubedl-android` Maven coordinates identify actual inherited artifacts. They are not changed to invented Seali coordinates. See [native dependency provenance](docs/NATIVE_DEPENDENCY_PROVENANCE.md) for the known source and license gaps. Repository branding alone does not close those gaps or prove that replacement native builds exist.

## Compatibility identifiers still present

Owned Kotlin packages, the color namespace, test selectors and new notification action keys use `com.frpboy.seali`. The installed Seali application ID remains `com.frpboy.seali`. Minimal legacy type-ID input mappings, component names and one receiver bridge remain only to read earlier Seali state and keep old explicit intents resolvable. Required upstream attribution and real dependency coordinates are unchanged. See [namespace migration notes](docs/migration/owned-namespace-migration.md); source preparation is not an installed-upgrade qualification.

The inherited [Seal issue 1399](https://github.com/JunkFood02/Seal/issues/1399) is retained here as a specific upstream technical reference, not a Seali reporting destination. Current Seali bug reporting and contribution links point to this repository. Inherited sponsor-generation and automatic issue-closure workflows remain disabled; they are not activated merely by changing the repository name.
